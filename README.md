# MySirat

An ad-free Muslim toolkit app for Luton by SMR Digital: prayer times, qibla, local masjids and Jummah finder, Qur'an and duas, Islamic videos, local news and a halal directory.

- `app/` — the app (open `app/index.html`)
- `build/build_app.py` — rebuilds `app/` from `sources/`
- `tools/make_smr_demo.py` — adds or updates it in the SMR Digital demo manager

Read **HANDOVER.md** first.
