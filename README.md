# SMR website

Static site for smrgraphics.co.uk and smrdigital.co.uk: SMR Graphics, SMR Digital and SMR Plates.

- `index.html`: the whole site (styles, content and scripts)
- `plate.js`: number plate preview renderer used by the plate builder
- `assets/`: logos, photos, client logos and mockups

Every push to `main` uploads the site to the web server automatically (see `.github/workflows/deploy.yml`).
